# Souad Eroui — Front-End Developer Portfolio

A responsive Next.js portfolio built from the information and project links in Souad's CV.

## Included
- Personal portrait (`public/souad-profile.jpg`)
- English portfolio with About, Projects, Skills, Education and Contact sections
- Four live project links from the CV
- Responsive desktop and mobile styling

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open the terminal in this folder and run:

```bash
npm install
npm run dev
```

4. Open http://localhost:3000

## Customize
- Main content and project links: `app/page.js`
- Design and responsive styles: `app/globals.css`
- Profile photo: replace `public/souad-profile.jpg` with another image using the same filename.
- Contact email is currently set to `erouisouade2@gmail.com`.
